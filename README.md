# minigame-offline-trainer 在线课件

在线地址：https://csvwolf.github.io/minigame-offline-trainer/

这是仅用于 GitHub Pages 的独立发布分支，不包含技能安装入口。
技能安装请使用 main 分支：https://github.com/csvwolf/minigame-offline-trainer

- `index.html`：18 页网页课件，内置字体、脚本与独立提词窗口。
- `narration.md`：逐页口播稿。
- `narration.txt`：纯口播稿。
- `usage.txt`：课件操作说明。
- `THIRD-PARTY-NOTICES.txt`：样式和字体许可说明。

方向键翻页，P 打开提词窗口，F 全屏，H 进入录制模式。
本分支只发布公开课件，不包含游戏包、资源或用户存档。
