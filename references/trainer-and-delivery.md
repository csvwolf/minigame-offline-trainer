# 修改器与交付

## 修改器设计

优先使用原游戏的资源、装备、配置、事件和保存接口。核对参数类型、范围和生命周期，不只检查函数能否被调用。Unity/WASM 或装备/速度功能参见 [客户端实现经验](client-techniques.md)。

先完成 [基础修改能力盘点](original-flow-and-verification.md#基础修改能力与默认值)，再扩展外围选项；保持原游戏页面与可选修改器的边界。首启、累计统计、真实伤害及页面切换验收见同一参考。

界面采用可记忆的折叠分类、紧凑可触控按钮和可调数量。顶部「返回游戏/关闭」与免费声明固定，只有内容区滚动；不是把按钮放在会被长面板滚走的首行。悬浮修改器入口默认可拖动并记忆位置，限定在可视区域内，适配窗口尺寸/方向变化；点击打开与拖动移动需区分，拖动结束不误开面板、不向游戏穿透触摸。全屏/模态面板本身无需强行拖动，确有遮挡的浮动面板则提供拖动手柄。活动/任务弹窗应有与倒计时、领奖条件独立的关闭入口；不能因为结算按钮尚未解锁而困住玩家。检查原关闭/返回与移动设备返回键，退出不得误发奖励或丢失已保存进度。用户以武器举例时，检查是否需要覆盖装备各部位。隐藏当前任务无关的选项，区分“每种数量”与“合计数量”；避免向游戏穿透点击。尚未就绪和范围错误应反馈明确。

修改前备份、修改后保存并读回。清理必须先预览再确认，确认绑定范围、门槛和候选清单；严格小于门槛，保留边界、穿戴和未选中的材料。批量调用原移除接口，避免逐件刷新引起卡顿；撤销时阻止旧页面保存覆盖恢复数据。

区分持续掉帧、首次加载、进门尖峰。先检查修改器是否每帧重复写状态、刷新 UI、后台计时；同场景比较后再判断设备、渲染或资源瓶颈。Android gfxinfo 不等于 Unity FPS；引擎时间倍率不保证负载下真实墙钟倍率。

## 移动端兼容与滚动

实现或修改 WebView 壳、长浮层和移动表单时，读取 [移动 WebView 与滚动](mobile-webview.md)。保留旧内核高度兜底，较新单位用能力分支隔离；验证实际计算尺寸与原生触摸到底，不能把 Android 版本、物理分辨率或桌面模拟当作完整兼容证明。

## 默认去广告与平台入口奖励

离线版默认去广告。已确认广告成功后的原客户端奖励能本地结算时，让原游戏奖励按钮直接执行该奖励路径；不额外提供含糊的「本地广告奖励」开关，也不把用户点击奖励理解为额外的网络授权。

统一检查广告、入口/侧边栏有奖、添加桌面、收藏/关注等宿主依赖：追踪可见/可领条件、成功回调参数、奖励数量、领取记录和冷却。可在离线副本解除已确认的入口条件并复用原领奖代码，保留原每日/一次性/冷却限制和存档。不要只删除平台调用而让领奖按钮无响应，也不要猜测成功参数类型。

区分本地领奖与实际平台动作：离线领取不代表已在平台关注/收藏、创建了宿主快捷方式或完成线上任务。桌面安装入口与游戏奖励是两件事；说明实际提供的范围。未知或服务器独占的奖励不得一律返回成功，不伪造或提交平台、广告、支付、账号凭证。

验收须点击原奖励入口，核对原配置数量、余额入库、重复领取限制、跨日/冷却后状态和保存重启；仅确认 success 回调执行不算领奖验收。

成功回调后的广告统计命令、每日任务和累计档位也要接通，并验证一次成功只计一次、普通免费领取不误计。累计在线领奖与会话起点的关系按 [累计时长与领奖统计](original-flow-and-verification.md#累计时长与领奖统计) 处理，不能为了修复一个入口在多处重复加数。

## 游戏倍速与自然天

有持续战斗、生产或等待玩法时，默认检查并提供可恢复的游戏倍速入口；优先使用该版本已确认的引擎时间或原速度接口，给出正常速度和适合实际运行的倍率。区分统一模拟时间与原游戏某个局部加速，说明两者是否叠加，核对移动、动画、齿轮/生产、技能/刷怪计时，不能只改显示文字或某一动画。打开面板暂停与返回恢复不得丢失倍率；倍率作为本机设置记忆，不覆盖进度的撤销备份。引擎倍率不保证负载下实际墙钟倍率。

有自然天、签到或日期解锁门槛时，区分经过时长、日历跨日、累计登录天数和连续签到；提供 +1 天/多天或目标日期等原语义相符的快进，不能把 +3 天自动当成登录了三次。仅调整离线副本的时钟或已确认时间接口，不修改设备系统日期，不影响线上原游戏。显式历史时间戳的解析不能被再次偏移，游戏模拟倍速不得顺带加速日历。

快进前备份游戏进度和虚拟时间设置，变更后按原生命周期刷新/重载并说明是否结束当前局。验证实际日期门槛、每日奖励、计时、重启、撤销与备份迁移；恢复真实日期不等于撤回已经领取或解锁的进度，需明确恢复范围。不存在对应时间门槛或用户限定为分析时，不为凑功能增加无效按钮。

## 有关卡游戏的默认功能

制作有关卡或章节的离线版/修改器，默认交付**关卡解锁与快速跳关**，用于快速体验后续内容和解锁新功能，不留到用户再次要求才补做。

- 提供「解锁下一关/章」和「跳到指定关/章」。若养成、副本、角色或玩法由通关进度解锁，定位门槛并提供相应快捷入口；名称与目标从该游戏原配置确认。
- 区分当前选择、最高已通关、最高已解锁等状态，追踪原功能解锁、保存和界面刷新逻辑。通过原接口写入正确进度并触发解锁，不能只改关卡标题或当前场景。回跳较早关卡保留更高的解锁进度；不要将某款游戏的字段、章节数量或门槛当作通用常量。
- 目标限定为已采集且有效的关卡，拒绝空值、小数、越界和不存在的关卡。达到本版上限后明确显示状态；服务端独占、资源缺失或原版未实现的内容说明限制，不能用万能成功返回声称已解锁或可玩。
- 每次操作前备份，修改后保存。界面明确提示是否结束当前局、返回首页或影响引导；需要重启/重建场景时防止旧状态覆盖新进度，引导变化使用已确认的原完成接口。提供撤销恢复，不在用户真实进度上试验。
- 默认只推进解锁所需的进度，不额外发放被跳过关卡的结算、任务或宝箱奖励，不自动提高角色属性；用户另有明确要求时按其要求实现。
- 入口放在可选修改器中，保留原地图、结算和新功能解锁弹窗。按实际绑定辨认锁图标；未接入的预留菜单不编造解锁能力。重做适配时保留已授权的跳关能力，避免和自制游戏流程一起误删。
- 在隔离存档验证实际按钮、跨功能门槛后的原入口可用、合法范围与非法目标、回跳、保存重启、备份撤销及当前局退出。分别报告解锁入口与实际玩法的验证范围；解锁成功不等于所有后续关卡已通关。

## 应用图标

默认保留**经核实的原游戏官方图标**，使安装入口与游戏身份一致；用户指定其他图标时按其要求执行。

- 从平台官方详情/接口或原游戏包确认图标与目标游戏身份一致，保存来源、原图尺寸和摘要。不要把宿主平台图标、游戏内资源图集或同名游戏的图片当作应用图标；没有可靠来源时明确标注临时图标或未验证，不声称已核实官方图标。
- 保留原图内容、比例和清晰度，不擅自重绘、换色或加字。只做目标平台必要的尺寸、留白和遮罩适配；查看透明背景、圆形裁切和自适应图标效果，避免拉伸、模糊或主体被裁掉。
- 按交付平台检查实际配置：APK 的 manifest icon/roundIcon 与最终资源；H5 的 favicon；PWA 的 manifest icons、尺寸与适用的 maskable 配置。每种入口只检查本次实际交付的形式，不为图标额外扩展交付平台。
- 从最终产物提取或读取图标并与已确认的原图比较。PNG 重编码、压缩或元数据变化可能改变文件摘要；有这类差异时用解码后的像素或已说明的缩放/遮罩结果核对，不能仅凭文件名、源码引用或 PNG 字节摘要判断图标正确。
- 安装后检查可用验收设备的桌面/启动器实际显示，并区分包内资源正确与设备显示正确。没有对应设备时注明显示未验收；更新图标时沿用包名、签名与正常版本升级，不通过卸载或清除游戏数据解决图标问题。
- 图标来源和验证结果随项目归档，实际游戏图标留在该项目资源中，不加入通用技能仓库。

## 离线适配与交付选择

先使资源加载和持久化正常，再实现实际用到的宿主 API。请求按已知资源映射到本地，未知外联应能诊断，不能一律伪装成功。验证首次启动、断网、重启和存档读回。

- H5 不同 origin 的存档隔离；不能默认电脑、手机、PWA、APK 之间自动继承。
- PWA 需要可信上下文、缓存完整性、冷启动和升级策略；局域网 HTTP 不等于 iOS 可离线安装的 PWA。
- APK 可使用本地 HTTPS origin 的 WebView；限制资源请求和导航。外部作者链接由用户点击后交给浏览器，避免替换游戏页。更新沿用包名与签名并提高版本号，不通过卸载/清数据解决普通问题。
- 签名私钥单独保管，不加入 Git、同步技能或交付源包。丢失私钥后不能声称新生成的密钥可覆盖原安装。

## 验证、归档与同步

使用隔离研究存档测试发放/清理/回滚，不在用户真实进度上试验。分别报告实现、验证、打包、安装与未验证平台。保持同签名升级，记录版本、摘要和测试结果。

用户要求 Git 管理时沿用已有私有仓库；没有时在授权范围创建私有仓库。以明确文件清单入库，排除登录态、存档、抓包、签名密钥和设备配置。游戏资源只在用户授权与适当范围保管，第三方内容不进入通用技能。技能共享使用现有 skill-sync 工作流，核对本机安装和远端提交；未操作的设备只能称为待同步。
